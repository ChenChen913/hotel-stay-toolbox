# 🏨 酒店入住工具箱（hotel-stay-toolbox）

围绕「一次入住行程」的规则驱动工具：**入住前准备清单（含数量与购买建议）→ 入住检查 → 退房检查 → 知识库**。

- 无后端、无账号：行程存浏览器 localStorage，换设备/清缓存会丢数据
- 手机优先，电脑打开同样可用
- 不用 AI：清单由固定规则生成（每个问题都必须能回答「这个答案会改变什么」）

## 在线使用

GitHub Pages：<https://chenchen913.github.io/hotel-stay-toolbox/>（推送 main 后自动部署）

## 本地使用

直接双击打开 `index.html` 即可（纯静态，无构建）。

## 目录

| 文件 | 作用 |
|---|---|
| `index.html` | 单文件静态站（UI + 交互） |
| `data.js` | 物品规则 / 两份固定检查清单 / 10 条知识种子条目（带证据等级与来源） |
| `engine.js` | 规则求值（人数→数量、条件→物品）+ 行程存取 |
| `test.js` | 规则引擎自检，`node test.js`（当前 29 项全过） |
| `docs/规则表.md` | **keystone 设计文档**：问卷→条件→物品→数量公式的完整规则表 |
| `内容审查与扩充方案.md` | 内容层的审查与扩充方案（40 条目清单、信息架构、证据分级） |
| `fact-check-法律与投诉渠道核查.md` / `酒店偷拍核查报告.md` | 两个专题的事实核查报告（法律/维权、偷拍检测方法真伪） |
| `酒店入住指南.html` | 项目的原始起点（个人经验版指南，内容已被上述审查处置） |
| `_fc/` | 核查引用的原始官方文件（GB 55037、文旅领域重大事故隐患判定标准等） |
| `聊天记录/` | 产品定义阶段与 ChatGPT 的讨论记录（产品从「指南」演进为「行程工具箱」的过程） |

## 知识内容的可信度约定

所有知识条目标注证据等级（🔵 官方法规 / 🟢 官方建议 / 🟡 专业机构 / ⚪ 个人经验）与风险等级（🟢 / 🟡 / 🔴），并带来源与核查时间。**不收录**会制造错误安全感的伪检测方法（指尖测镜、手机红外 APP 等——已有权威定论，见知识库）。
