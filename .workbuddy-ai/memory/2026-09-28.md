## 修两个被前 AI 改坏的小功能

- 日期选择器：原本 step1 露出的是浏览器原生 `<input type="date">`，跟玻璃风完全脱节；且「自选日期」chip 高亮绑定的是 `isOffset(-1)`（永真），点了也不会亮。
  → 新增 `src/components/DatePicker.vue`：纯自定义月历，月历行/星期/日期格全部走玻璃卡 + 松针渐变；今天用金色小点标记、选中日松针深绿渐变填充。
  → `WizardView.vue` step1：用 `<DatePicker v-model="draft.date">` 取代原生 input；自选 chip 改绑 `customDate`；附带「退房 X月X日 · 周X · 共 N 晚」一行即时反馈。

- 衣物下拉遮挡：`.cpanel` 之前是 `position:absolute + z-index:20`，但其祖先 `.glass` 卡片带 `backdrop-filter`，**创建独立层叠上下文**——所以下拉再高 z 也飞不出这张卡，被下面的兄弟卡片和底部导航栏盖住。
  → `ClothingAdd.vue` 改用 `<Teleport to="body">` + `position:fixed + z-index:1000`，彻底脱离祖先层叠上下文；按触发器位置计算 top/left/maxH，空间不够时向上翻；二遍测量校正；外面点击 / Esc / 滚动重定位都接上。NAV_RESERVE=76 避免压到底部导航栏。

## 项目小约定（顺手记一下）
- 玻璃卡片 `.glass` 一律带 `backdrop-filter`，会形成层叠上下文——**任何需要在卡片上方浮层的东西（popover/下拉/菜单/对话框）都应该 Teleport 到 body 再 fixed 定位**，否则会被同辈玻璃卡片盖住。底部导航栏 z-index:10，浮层至少 1000。
- 原有 chip 高亮绑定务必用「显式状态字段」而不是借用某个 mock 计算函数（这里踩了坑）。
