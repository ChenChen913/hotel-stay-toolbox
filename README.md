# 🏨 酒店入住工具箱（hotel-stay-toolbox）

围绕「一次入住行程」的规则驱动工具：**入住前准备清单（含数量与购买建议）→ 入住检查 → 退房检查 → 知识库**。

- 无后端、无账号：行程存浏览器 localStorage，换设备/清缓存会丢数据
- 手机优先，电脑打开同样可用
- 不用 AI：清单由固定规则生成（每个问题都必须能回答「这个答案会改变什么」）

## 在线使用

GitHub Pages：<https://chenchen913.github.io/hotel-stay-toolbox/>（push 到 main 后由 GitHub Actions 自动构建部署）

## 技术栈

Vite 6 + Vue 3 + TypeScript + Vitest + lucide-vue-next（细线 SVG 图标）。UI 为「精品酒店 × 液态玻璃」设计系统（backdrop-filter 玻璃卡片、60-30-10 配色、衬线标题、tabular-nums 数字组件）。

```bash
npm install     # 安装依赖
npm run dev     # 本地开发（Vite 热更新）
npm test        # 规则引擎测试（Vitest）
npm run build   # 类型检查 + 产物构建（dist/）
npm run preview # 本地预览构建产物
```

## 目录

| 路径 | 作用 |
|---|---|
| `src/data.ts` | 物品规则 / 两份固定检查清单 / 知识种子条目（带证据等级与来源） |
| `src/engine.ts` | 规则求值（人数→数量、条件→物品）+ 行程存取 |
| `src/store.ts` | 视图状态 + 日期格式化 |
| `src/components/` | 视图与组件（首页 / 向导 / 行程 / 知识库 / 行组件 / 步进器 / 开关） |
| `src/styles/global.css` | 设计系统：色板、玻璃卡片、圆勾选框、iOS 开关、分段页签 |
| `tests/engine.test.ts` | 规则引擎测试（数量公式、年龄门控、长住、持久化） |
| `docs/规则表.md` | **keystone 设计文档**：问卷→条件→物品→数量公式的完整规则表 |
| `内容审查与扩充方案.md` | 内容层的审查与扩充方案（40 条目清单、信息架构、证据分级） |
| `fact-check-法律与投诉渠道核查.md` / `酒店偷拍核查报告.md` | 两个专题的事实核查报告 |
| `_fc/` | 核查引用的原始官方文件 |
| `聊天记录/` | 产品定义阶段与 ChatGPT 的讨论记录 |

## 知识内容的可信度约定

所有知识条目标注证据等级（官方法规 / 官方建议 / 专业机构 / 个人经验，以色点呈现）与风险等级（注意 / 建议检查 / 立即处理），并带来源与核查时间。**不收录**会制造错误安全感的伪检测方法（指尖测镜、手机红外 APP 等——已有权威定论，见知识库）。
